# Verfahrensvergleich

Die vier Bauteil- und Anlagen-Gruppen haben jeweils eine Empfehlung für **ihren** Bereich entwickelt: Dach, Fenster, Kellerdecke, Anlagentechnik. Aus vier einzelnen Empfehlungen wird jetzt eine gemeinsame **Gesamtstrategie für Familie Schmitt**.

Das ist der Kern der Beratungsleistung – und der Grund, warum die Vier-Gruppen-Aufteilung überhaupt sinnvoll war. Eine gute Sanierungsempfehlung ist mehr als die Summe ihrer Teile: Sie priorisiert, sie berücksichtigt Wechselwirkungen zwischen den Maßnahmen, und sie entwickelt einen realistischen Zeitplan.

!!! info "Zweck dieses Kapitels"
    Dieses Kapitel ist **nicht** für eine weitere Gruppenarbeit gedacht. Es strukturiert die **Klassensitzung**, in der die vier Gruppen ihre Ergebnisse zusammenführen. Ihr braucht dafür:

    - **Präsentationsergebnisse aller vier Gruppen** (Empfehlung, Zahlen, Argumente)
    - **Die $H_T$-Ausgangstabelle** aus der [Phase-2-Übersicht](uebersicht.md)
    - **Etwa 90 Minuten** für die vollständige Synthese

## Ablauf der Vergleichssitzung

Die Sitzung läuft in fünf Schritten. Sie folgt einer Logik: **Zahlen sammeln → Zahlen einordnen → Reihenfolge bestimmen → Empfehlung formulieren**.

### Schritt 1 – Gruppenpräsentationen (je 12 Minuten)

Jede Gruppe präsentiert nacheinander:

- Dach
- Fenster
- Kellerdecke
- Anlagentechnik

Nach jeder Präsentation: **3 Minuten Rückfragen und Diskussion**, dann übernimmt die nächste Gruppe.

Wichtig für die zuhörenden Gruppen: **notiert die Kernzahlen**, ihr braucht sie im nächsten Schritt.

### Schritt 2 – Die Gesamt-Bilanz-Tabelle

Diese Tabelle wird während der Präsentationen (oder direkt danach) an der Tafel gefüllt. Sie ist der zentrale Ankerpunkt der gesamten Synthese.

| Maßnahme | $\Delta H_T$ in W/K | Endenergie-Einsparung in kWh/a | Kosten-Einsparung in €/a | CO₂-Einsparung in kg/a | Eigenanteil in € | statische Amortisation |
|---|---|---|---|---|---|---|
| Dach (empfohlene Variante der Gruppe) | | | | | | |
| Fenster (empfohlene Variante der Gruppe) | | | | | | |
| Kellerdecke (empfohlene Variante der Gruppe) | | | | | | |
| Anlagentechnik (empfohlene Variante der Gruppe) | | | | | | |
| **Summe** | | | | | | – |

**Zur Anlagentechnik:** Die WP-Zeile ist keine „Sanierungsmaßnahme am Bauteil" – sie ersetzt den Wärmeerzeuger. Die Werte in dieser Zeile beziehen sich auf den Umstieg vom Gaskessel auf die Wärmepumpe. Die $\Delta H_T$-Spalte bleibt für die Anlagentechnik **leer** (die WP verändert $H_T$ nicht), aber die Endenergie-Einsparung ist deutlich sichtbar.

**Diskutiert nach dem Ausfüllen:**

- Welche Maßnahme hat die **größte Endenergie-Einsparung** absolut?
- Welche Maßnahme hat die **kürzeste Amortisation**?
- Welche Maßnahme hat den **niedrigsten Eigenanteil**?
- Welche Maßnahme hat den **schlechtesten Wirtschaftlichkeits-Kennwert** – und warum empfehlt die zuständige Gruppe sie trotzdem (oder eben nicht)?
- Gibt es eine **Maßnahme, die keine Gruppe empfiehlt**? Warum?

### Schritt 3 – Priorisierungskriterien diskutieren

„Alles gleichzeitig sanieren" ist selten realistisch. Die Familie muss **eine Reihenfolge** wählen. Bevor ihr diese festlegt, klärt gemeinsam, **welche Kriterien** die Reihenfolge bestimmen sollen.

Mögliche Kriterien – nicht alle sind gleich wichtig:

| Kriterium | Wirkung auf die Reihenfolge |
|---|---|
| **Wirtschaftlichkeit** (kürzeste Amortisation zuerst) | Maßnahmen mit hohem Wirkungsgrad pro € vorziehen |
| **Baulicher Zusammenhang** | Wenn eine Maßnahme die andere voraussetzt: Reihenfolge zwingend |
| **Anlassbezogener Zwang** | Defekte Anlagenteile (Heizkessel!) diktieren die Reihenfolge |
| **Förderung / Zeitfenster** | BAFA-Konditionen können auslaufen oder sich verschlechtern |
| **Belastung der Familie** | Nicht mehrere große Baustellen in kurzer Zeit |
| **Liquidität** | Familie muss die Investitionen finanzieren können |
| **Wärmepumpen-Vorbereitung** | Hülle muss ein Niveau erreichen, bevor WP effizient läuft |
| **Klimarelevanz** | CO₂-schwerste Maßnahmen zeitlich vorziehen |

Diskutiert **im Plenum:**

- Welche dieser Kriterien sind für Familie Schmitt entscheidend?
- Was ergibt sich, wenn ihr nach **rein wirtschaftlichem** Kriterium priorisiert?
- Was ergibt sich, wenn ihr nach **klimapolitischem** Kriterium priorisiert?
- Welches Kriterium wiegt für euch am schwersten – und warum?

### Schritt 4 – Sanierungsfahrplan entwickeln

Jetzt entwickelt ihr aus den priorisierten Kriterien einen **konkreten Sanierungsfahrplan** mit Zeithorizont.

**Wichtiger Anker:** Der Auslöser der Beratung war die defekte Heizung. Die Anlagentechnik-Entscheidung muss **jetzt** getroffen werden. Damit die Wärmepumpe effizient läuft, muss die Hülle ein bestimmtes Niveau erreicht haben – Phase 1 (WDVS) ist gemacht, aber vielleicht braucht es noch mehr, bevor die WP eingebaut wird.

Vorlage für den Sanierungsfahrplan:

| Zeitraum | Maßnahme | Begründung | Investition |
|---|---|---|---|
| **Sofort (2026)** | | | |
| **Kurzfristig (2027–2028)** | | | |
| **Mittelfristig (2029–2030)** | | | |
| **Langfristig (nach 2030 oder anlassbezogen)** | | | |

Beim Ausfüllen:

- Welche Maßnahme **muss** sofort passieren? (Die kaputte Heizung diktiert etwas – aber die Wärmepumpe muss auf eine passende Hülle treffen.)
- Welche Maßnahmen **können warten** – und wie lange?
- Gibt es **Kopplungen** (z.B. Fenstertausch besser nach WDVS, weil die Fenster in die Dämmebene versetzt werden müssen)?
- Wo sind **Anlassmomente** sinnvoll (z.B. Dach nur bei Eindeckungserneuerung)?

### Schritt 5 – Gesamtempfehlung formulieren

Am Ende steht eine **schriftliche Gesamtempfehlung an Familie Schmitt** – das eigentliche Beratungsprodukt. Sie soll:

- **einleitend** den Ist-Zustand und die getroffenen bisherigen Entscheidungen (WDVS-Sanierung) einordnen,
- **die konkrete Empfehlung** für jede Maßnahme aussprechen, mit klarer Priorität und Zeithorizont,
- **die tragende Argumentation** benennen (nicht jede Einzelrechnung wiederholen, aber die Kernlogik erklären),
- **die Gesamtkosten und Gesamtwirkung** abschätzen: welchen $H_T$ erreichen wir am Ende, wieviel Endenergie sparen die Schmitts insgesamt, wieviel CO₂?
- **auf Rückfragen** vorbereitet sein: „Warum diese Reihenfolge?", „Was passiert, wenn wir Maßnahme X weglassen?", „Wie ändert sich das, wenn die Gaspreise steigen?"

Die Empfehlung sollte 1 bis 2 Seiten haben – kein Kurzsatz, aber auch kein Fachaufsatz. Sie wird von der Energieberaterin mit der Familie besprochen; die Familie muss sie **verstehen** können, nicht die Formeln nachrechnen.

## Die Rolle der Wärmepumpe – nochmal zum Verständnis

Ein Punkt, der in der Vergleichssitzung oft übersehen wird: Die Wärmepumpe ist **kein weiteres Bauteil**, sondern das **Anschlussstück** an alle Hüllenmaßnahmen.

- Je besser die Hülle, desto niedriger die Vorlauftemperatur, desto höher die JAZ, desto niedriger die Stromkosten der WP.
- Je schlechter die Hülle, desto höher die Vorlauftemperatur, desto niedriger die JAZ, desto teurer der Betrieb.

Das heißt: Die Wärmepumpe **profitiert** von jeder Bauteilsanierung. Und umgekehrt: Der Nutzen jeder Bauteilsanierung wird **verstärkt**, wenn danach eine Wärmepumpe kommt (weil dann nicht Gas, sondern Strom eingespart wird – und Strom wird über die Jahre klimafreundlicher).

Diese wechselseitige Verstärkung ist der Grund, warum die Empfehlungsstrategie **integriert** gedacht werden muss und nicht als Summe unabhängiger Einzelmaßnahmen.

## Kreisschluss zur Lernsituation

Am Anfang der Phase 1 stand die Frage der Energieberaterin: *„Lassen Sie uns über die neue Heizung reden, nachdem wir über Ihre Außenwände gesprochen haben."*

Jetzt seid ihr am Ende des Weges. Über die Außenwand (Phase 1) und über alle weiteren Bauteile und Anlagen (Phase 2) habt ihr gesprochen. Aus dieser Fachlichkeit entsteht **die eigentliche Beratungsleistung**: Nicht die einzelne Rechnung, sondern die Fähigkeit, eine komplexe Sanierungsfrage in eine strukturierte, verständliche Empfehlung zu übersetzen.

Die Schmitts werden am Ende **eure Empfehlung** in ihren Händen halten. Mit dieser Empfehlung entscheiden sie, ob und wie sie ihr Haus sanieren – und ob sie euren Beratungsergebnissen vertrauen.

Das ist genau das, was Energieberatung im Alltag ausmacht.

Umgekehrt: eine gut kommunizierte Kompromissempfehlung wirkt oft mehr als eine fachlich strengere Vorgabe. Das ist keine Schwäche der Fachlichkeit, sondern ihre Ergänzung.</p>
